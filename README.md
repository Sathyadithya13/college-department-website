
# College Department Website

## Project Description
A simple website for the Computer Science and Engineering department, built using HTML and CSS.

## Objectives
- Create a home page.
- Display faculty details.
- Display department contact information.
- Practice Git and GitHub collaboration.
- Create feature branches and merge changes.
- Create and resolve a merge conflict.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- Visual Studio Code

## Project Files
- index.html - Home page
- faculty.html - Faculty page
- contact.html - Contact page
- style.css - Website design
- README.md - Project documentation

## Git Branches
- main
- feature/home
- feature/faculty
- feature/contact
- feature/home-update
- feature/home-design
