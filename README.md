# College Department Website

## Project Description
A simple website for the Computer Science and Engineering department, built using HTML and CSS.

## Objectives
- Create a home page.
- Display faculty details.
- Display department contact information.
- Practice Git and GitHub collaboration.
- Create and merge feature branches.
- Create and resolve a merge conflict.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- Visual Studio Code

## Project Files
- index.html - Home page
- faculty.html - Faculty page
- contact.html - Contact page
- style.css - Website styling
- README.md - Project documentation
